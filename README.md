# luiscarlosrodriguez.com

Personal site for Luis Carlos Rodriguez — Solution Architect & Delivery Lead.

Static single-file site. No build step, no dependencies.

- `index.html` — the entire site (HTML, CSS, and JS inlined)
- `Luis-Carlos-Rodriguez-CV.pdf` — CV, linked from the hero and contact sections

## Deploying

Hosted on Vercel, connected to this repo. Any commit to `main` deploys automatically.

Vercel project settings:
- Framework preset: **Other**
- Build command: *(none)*
- Output directory: *(none — served from repo root)*

## Editing

Open `index.html` in any editor, commit, push. That's the whole workflow.
